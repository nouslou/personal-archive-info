Privacy policy

Personal Archive uses rclone with the drive.file permission to copy and check files. File contents, names and metadata pass directly between the Mac and Google Drive. This website receives no archive files or access tokens.

Tokens are saved in a local rclone configuration only after the user approves the connection and local saving. Local logs may contain filenames and errors. The user controls retention of configuration, logs and Drive copies.

The user can revoke access in Google Account connections settings. Revocation does not delete existing Drive copies.

This site adds no forms, analytics, tracking scripts or cookies. GitHub Pages logs visitors' IP addresses for security; see the GitHub Privacy Statement.
